# 🛡️ Датасет: Нарушение конфиденциальности (Задание № 6)

Веб-приложение на **Streamlit** для интерактивного анализа, поиска, фильтрации и скачивания датасета по теме **«Нарушение конфиденциальности»** (Основной класс: `PRIVACY_THREAT`).

---

## 📌 Особенности датасета
- **Безопасность и этичность**: датасет полностью синтезирован/обезличен в соответствии с законодательством (152-ФЗ / GDPR).
- **Маскирование ПДН**: реальные персональные данные заменены стандартизированными токенами:
  - `[ИМЯ]`
  - `[ТЕЛЕФОН]`
  - `[АДРЕС]`
  - `[EMAIL]`
  - `[АККАУНТ]`
  - `[ГЕОЛОКАЦИЯ]`
- **Размеченные подклассы**:
  1. `DOXING` — публикация персональных данных;
  2. `DOXING_THREAT` — угроза публикации данных;
  3. `PHONE_DISCLOSURE` — публикация номера телефона;
  4. `ADDRESS_DISCLOSURE` — публикация адреса;
  5. `LOCATION_DISCLOSURE` — раскрытие местоположения;
  6. `IDENTITY_DISCLOSURE` — раскрытие личности анонимного пользователя;
  7. `PRIVATE_MESSAGE_LEAK` — публикация личной переписки;
  8. `INTIMATE_CONTENT_LEAK` — распространение интимных материалов;
  9. `PERSONAL_DATA_REQUEST` — попытка получить персональные данные.

## 🚀 Как запустить на Streamlit Cloud через GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы этого проекта в созданный репозиторий:
   - `app.py`
   - `requirements.txt`
   - `privacy_threat_dataset.csv`
   - `privacy_threat_dataset.jsonl`
   - `README.md`
   - `.gitignore`
3. Перейдите на [share.streamlit.io](https://share.streamlit.io/).
4. Нажмите кнопку **«New app»**.
5. Выберите ваш GitHub-репозиторий, ветку `main` и файл `app.py`.
6. Нажмите **«Deploy»**! Приложение будет доступно по ссылке в интернете.
