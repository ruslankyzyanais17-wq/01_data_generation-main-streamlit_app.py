## Новое в версии 2.0

Эта версия продолжает исправленную копию, а не повреждённые исходные CSV. Все четыре файла данных сохранены байт в байт относительно первого обновления. Меняются интерфейс и инструменты анализа.

### 1. Обзор и удобный каталог

Навигация «Обзор / Каталог / Качество» отделяет разные задачи. Общие фильтры действуют во всех разделах; над содержимым показаны их состояние и размер выборки. Расширенные списки платформ, подклассов и источников свёрнуты, чтобы не занимать весь экран.

В каталоге доступны страницы по 25, 50 или 100 строк. Изменение фильтров, размера страницы или режима списка возвращает на первую страницу; переключение между разделами сохраняет страницу и выбранную запись. Режим «Показывать только уникальные тексты» оставляет в списке по одному представителю каждого точного текста. Он **не удаляет данные из выгрузки**: полный и фильтрованный экспорт сохраняет все соответствующие записи.

### 2. Карточка записи

Под таблицей выберите ID на текущей странице. Карточка показывает полный текст, подкласс, язык, исходное описание source, группу платформ и присутствующие токены. Отдельно видны число точных совпадений во всём наборе и группа базового примера с числом вариантов текста. Можно посмотреть первые 10 связанных записей полного набора и скачать исходную запись как JSON.

Описание источника не превращается в выдуманную ссылку. Счётчики связанных записей относятся к полному набору, что явно подписано. Когда после фильтрации или смены страницы прежний ID больше не доступен, карточка открывает первую запись текущей страницы.

### 3. Проверка качества и отчёт

Панель анализирует весь набор или текущую выборку:

- отсутствующие/пустые основные поля, неверные типы/ID/коды языка/подклассы
- точные повторы текста, повторяющиеся ID, разные метки одного точного текста
- согласованность буквальных токенов с полями фрагмент_…
- баланс всех девяти подклассов и языков, включая нулевые категории
- возможные email, телефон, @аккаунт, координаты и адресные подсказки по открытым простым правилам

**PII-сигнал не подтверждает реальные персональные данные.** Проверка может ошибаться в обе стороны; имена и контекст идентификации надёжно не распознаются. Ноль сигналов не означает полную анонимность. Балл качества не придумывается.

JSON-отчёт содержит сводку, группы повторов, правила, ограничения и параметры сокращения подробностей. CSV содержит только индивидуальные замечания. Исходные тексты и совпавшие PII-фрагменты в эти отчёты не включаются: остаются номера строк, допустимые ID, правила и причины. Номера строк относятся к проверенному набору/выборке и начинаются с 1; это не всегда исходные ID.

Все записи проверяются. В отчёте максимум 1 000 индивидуальных замечаний, 1 000 групп каждого вида и первые 5 ID/позиций в группе. Полные счётчики и число опущенных подробностей сохраняются. Счётчик структурных замечаний считает срабатывания правил, а отдельный structural_issue_rows — затронутые строки.

Готовый отчёт для поставляемых 13 500 строк лежит в QUALITY_REPORT.json. В QUALITY_FINDINGS.csv сейчас только заголовок: индивидуальных замечаний по заданным правилам нет. Повторы отражены в JSON: 324 группы, 13 176 лишних повторных строк. Это ожидаемая характеристика шаблонного набора, а не автоматическая команда удалять записи.

### Дизайн и проверка

Используется спокойная светлая тема, контрастные подписи, нативные адаптивные блоки Streamlit и перенос полного текста. Настоящая браузерная/мобильная визуальная проверка в облачной среде оказалась заблокирована: Chromium завершался на запрещённом системном socket-вызове до открытия страницы. Скриншоты не создавались; внешний вид не выдаётся за визуально проверенный. Поведение проверяется через Streamlit AppTest. Диагностика ограничения сохранена в qa/BROWSER_QA_STATUS.json.

## Быстрый запуск на Windows

Распакуйте ZIP в **новую папку**, не поверх единственной копии проекта. Откройте терминал в папке, где лежат app.py и requirements.txt. Рекомендуемая проверенная версия — Python 3.12.

    py -3.12 -m venv .venv
    .\.venv\Scripts\python -m pip install -r requirements.txt
    .\.venv\Scripts\python -m streamlit run app.py --server.address 127.0.0.1

Откройте локальный адрес, который напечатает Streamlit, обычно http://127.0.0.1:8501. Активация PowerShell и изменение ExecutionPolicy не нужны. Если py недоступен, используйте путь к своему Python 3.12 вместо py -3.12.

На macOS/Linux:

    python3.12 -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt
    .venv/bin/python -m streamlit run app.py --server.address 127.0.0.1

Зависимости установятся из обычного Python-реестра; для установки нужен интернет. Для чтения локального набора после установки он не требуется. В этой среде проверены Python 3.12.14, Streamlit 1.65.0 и pandas 2.2.3. Сам Windows и PowerShell в проверочной среде не запускались.

## Работа с приложением

1. Языки, подклассы и платформы рассчитываются по текущим данным
2. Поиск буквальный и без учёта регистра: [ИМЯ], [, . и другие специальные символы не трактуются как регулярные выражения
3. Фильтры пересекаются. Пустой выбор в любом списке означает **ноль строк**. Кнопка «Сбросить фильтры» возвращает весь набор
4. «Перечитать локальные файлы» сбрасывает только кэш чтения. Никаких генерации, сбора, перезаписи или сокращения данных
5. В экспорте явно выбирается весь набор либо отфильтрованные строки. Порядок и исходные поля сохраняются
6. Обычный CSV: UTF-8 без BOM, разделитель запятая. Excel CSV: UTF-8 с BOM, разделитель точка с запятой. JSONL: UTF-8 без BOM, одна JSON-запись на строку
7. По умолчанию экспорт включает исходные 12 полей. Отдельная галочка добавляет три вычисленных поля

При отсутствии или повреждении основного JSONL выводится ошибка. Приложение **не подменяет его 48 базовыми примерами**.

- app.py — интерфейс, фильтры и выгрузки
- dataset_utils.py — проверка схемы, группировка платформ, поиск, сопоставление шаблонов и сериализация
- product_utils.py — пагинация, состояния фильтров и контекст карточек
- quality_report.py — независимые прозрачные правила качества, агрегаты и безопасные отчёты
- privacy_threat_dataset.jsonl — основной полный набор, исходные байты сохранены
- privacy_threat_dataset.csv — исправленная совместимая CSV-копия всех 13 500 записей
- privacy_threat_dataset_excel.csv — корректная CSV-копия для Excel
- dataset_source.json — исходные 48 базовых примеров; не заменяет полный набор
- generate_dataset.py — безопасный офлайн-экспорт существующего JSONL в **новую** папку; больше не генерирует дополнительные записи
- auto_collector.py — защитная заглушка старого входа: сообщает об отключении и завершается без сети и записи
- run_build.bat, run_build.ps1, build_13500.ps1, run_export.ps1 — совместимые локальные обёртки нового офлайн-экспорта; устаревшее имя build_13500 не означает размножение данных
- original_snapshot/ — оригинальные файлы для сравнения и сохранения авторской версии, **не запускайте эти старые скрипты**
- SOURCE_MANIFEST.json — источник, commit и SHA-256 всех оригинальных файлов
- tests/ — тесты целостности, функций и Streamlit AppTest
- .streamlit/config.toml — тема и отключение статистики использования Streamlit

Основная схема: id, sub_label, source, text, шесть фрагмент_… полей, language и is_anonymized. ID — уникальное положительное целое; language — непустой код; is_anonymized — JSON true/false. Некорректная схема вызывает понятную ошибку вместо молчаливой потери строк.

### Производные поля

- platform: нормализованная группа по **описанию** source, а не доказанный источник. X/Twitter объединены; составные описания вроде «Twitter / Reddit» остаются отдельной смешанной группой. Каждая запись учитывается ровно один раз
- base_example_id: ID однозначно совпавшего базового примера. Пусто, если совпадение не установлено либо неоднозначно
- origin_status: template_match при точном совпадении с известным примером/префиксным вариантом; иначе unverified. Это характеристика совпадения, **не подтверждённая история сбора**

Исходное поле source не менялось. Названия закрытых серверов, чатов и платформ в нём не подтверждают доступ к ним или фактический сбор данных там.

## Безопасное обновление своих данных

Перед любыми самостоятельными заменами сохраните резервную копию. Редактируйте или заменяйте полный privacy_threat_dataset.jsonl в собственной копии проекта только проверенными данными с описанным происхождением. Поле is_anonymized — авторская метка, а не результат автоматического аудита.

Чтобы получить совместимые CSV/JSONL **в отдельной новой папке**, используйте:

    python generate_dataset.py --output-dir exports_2026_10_09

Если папка уже существует, скрипт откажется её перезаписывать. Исходный JSONL, seed и основная папка приложения не меняются. Сначала все выходные файлы создаются во временной папке; новая папка становится доступна после успешной сериализации. Аргумент --source позволяет указать другой полный JSONL. Сбор сообщений, добавление новых примеров и увеличение числа строк здесь не выполняются.

После замены основного JSONL нажмите «Перечитать локальные файлы». При добавлении новых значений фильтров нажмите «Сбросить фильтры», чтобы включить их. Поставляемые тесты целостности фиксируют именно этот исходный снимок; после осознанной замены данных ожидаемые хеши/счётчики нужно пересмотреть, а не отключать проверки молча.

## Проверка

Из папки проекта, тем же Python, где установлены requirements:

    python -B -m unittest discover -s tests -v

Проверяется сохранение каждой записи и поля, Unicode, порядок строк, кодировки, поиск, фильтры, пустые результаты, перезагрузка, выгрузки и отказ при повреждённых данных. AppTest моделирует поведение Streamlit, включая навигацию, пагинацию, карточки и переключение отчётов; это не проверка кликов и скачивания файлов в настоящем браузере.

## Ограничения и этика

- Подтверждённых ссылок на первоисточники, дат сбора, согласий и протокола разметки не представлено. Не выдавайте шаблонные сообщения за фактические публикации конкретных людей
- Токены [ИМЯ], [ТЕЛЕФОН], [АДРЕС], [EMAIL], [АККАУНТ], [ГЕОЛОКАЦИЯ] не доказывают полную анонимность. Старый автоматический сборщик не умел надёжно удалять имена и адреса; его обещание «100%» было убрано из рабочей версии
- Независимая проверка приватности и правовых оснований не проводилась. Соответствие законам не гарантируется
- Повторы и близкие варианты одного шаблона создают риск **train/test leakage**. Не делите их случайно по строкам: группируйте по base_example_id, проверяйте похожие тексты и применяйте независимый контрольный набор. Неподтверждённые записи требуют отдельной проверки. Качество обучения модели не оценивалось
- CSV сохраняет исходные значения, не добавляя апострофы к потенциальным формулам. При работе с будущими непроверенными данными импортируйте текстовые колонки в Excel как текст
- Полного текста задания №6 нет: соответствие всем критериям задания не заявляется
- Эта поставка — обновлённые файлы. GitHub, Streamlit Cloud и исходный опубликованный сайт не изменены
